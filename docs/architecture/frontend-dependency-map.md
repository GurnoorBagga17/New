## Open interface proposals

1. **Audit stream union:** Team 5's decision `AuditEvent` and `KillSwitchAuditEvent` are separate. Agree a tagged union/event name plus SSE IDs, replay, heartbeat and backpressure.
2. **Identity/validator inspector:** current `IdentityContext` and decision audit omit the planned `rfc8707_aud_matched`, CIMD URI, tool-pin result, and normalized SQL/path/egress facts. Identify the producer and approve redacted fields before exposing them.
3. **Policy dry-run:** current backend candidate validation does not evaluate a sample MCP call. Decide whether to implement a separate simulation API or narrow the frontend operation.
4. **Policy bundle:** current reload is filesystem-based. Decide whether local API accepts policy text, a path, or a server-side reload command; define per-route mode changes and version preconditions.
5. **Revocation:** current target union lacks `session_id`; planned `/sessions/{id}/revoke` does not define the path ID's target kind or actor authorization. Resolve before enabling the UI action.
6. **D3:** agree whether emergency revocation overrides observe-only and publish the behavior before contract freeze.
7. **Browser exit evidence:** run Lighthouse, accessibility, and live event throughput tests. Current build/budget and static air-gap scans do not demonstrate those runtime properties.

Until each provider-owned interface is implemented and reviewed, frontend adapters must keep calls typed, same-origin and visibly unavailable on failure. Draft fixtures remain mock data and must not be described as live backend behavior.

# Axiom NHI Plugin

Local Antigravity workspace plugin for Axiom Non-Human Identity (NHI) governance.

## Features
- **Cedar Guardrail (`skills/cedar-guardrail`):** Validates SQL statements, filesystem paths, egress domains, and enforces fail-closed execution.
- **Benchmark Gate (`skills/benchmark-gate`):** Automates p50/p95/p99 latency testing (<1ms goal) and chaos resilience tests for Gate G1.
- **Architectural Rules (`rules/AGENTS.md`):** Enforces Apache-2.0 / MPL-2.0 boundaries, cryptographic payload hashing, and zero token exposure across all agent activities.
